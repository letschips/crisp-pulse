## 🌟 特色功能 (Highlights)

### 1. GitHub 风格年度知识脉冲热力图
- **统一的看板卡片**：概览、热力图、日明细使用同一套卡片结构，关键状态（连续天数、活跃天数、当天分数）直接显示在卡片右上角。
- **近 53 周活跃全景**：以经典的 GitHub 风格热力网格呈现全年的每一次输入与思考。
- **六维指标自由切换**：支持按综合贡献得分（Contribution）、活跃时长（Active Time）、新增词数（Words Added）、笔记产出（Notes Created）、任务完成（Tasks Completed）以及专注时长（Focus Time）查看热力图。
- **多时间跨度灵活分析**：近 53 周（全年）、最近 90 天、最近 30 天、最近 7 天以及本年度（YTD）。
- **看板顶部横幅**：视图顶部是一张渐隐的通栏横幅。默认是本地绘制的像素风天空（深色主题夜景、浅色主题白天），也可以在设置中换成库内图片，建议 3000×500 像素左右（宽高比 5:1 到 7:1，至少 1600×300），主体放在上半部分。尺寸不合适时设置页会提示。

### 2. 真实可信的有效编辑判定 (Credible Analytics)
- **拒绝虚假刷分**：引入分行差异指纹分析，即使是大范围修改与逻辑润色而总词数净增接近 0 时，也能准确识别“有效改写”并计入贡献。
- **任务生命周期校验**：仅对真正新增勾选的待办事项计分，取消勾选自动扣回，杜绝通过反复勾选复选框膨胀数据。
- **数据自愈与隔离**：启动时执行严格的数据契约校验，自动修复缺失节点，客观隔离未经验证的历史异常数据。

### 3. 透明清晰的贡献得分拆解
- **公式公开透明**：综合贡献得分由「新建笔记」、「有效编辑会话」、「任务达成」、「知识双链」、「深度润色」与「专注时长」按科学权重加权求和，分项之和严格等于总分。
- **直观卡片展示**：点击热力图任意一天，即时展开当日指标构成与清晰的分项拆解清单。

### 4. 知识复盘与报告
- **前后周期对比**：自选日期或最近 7/30/90 天，对比前一个等长周期；同时展示纳入、筛除与未记录天数。前期无记录或为零时不输出增长率。
- **目录与笔记钻取**：按目录查看全部笔记记录，可按新增词数、改写估算、任务与记录天数排序；每批展示 20 篇，可打开原笔记。
- **可保存的反思草稿**：进展、洞见与证据、阻塞、下一步分别填写，按区间和数据质量范围隔离；后台定期保存，也支持立即保存。
- **报告导出**：复制带周期对比、数据口径与反思的 Markdown 报告，或归档到设置中的库内目录。同区间、同范围的既有报告不覆盖。
- **口径说明**：目录占比是文件×日期记录数，不是工时；改写量是估算；贡献分不代表知识质量。未记录日期不视作零，历史路径随重命名更新。草稿保存在本地 `data.json`，备份会包含草稿。

### 4.1 来源、行动与证据
- **新增来源**：从 1.7.0 起，区分系统目录新增、大段捕获估算与其他未确认来源；历史记录不倒推分类，也不把未确认来源当成人工写作。
- **排除系统产物**：在复盘页或设置中主动开启，排除 `Sidecar/logs`、`Sidecar/backups`、`Sidecar/manifests` 的后续采集；历史、目录黑白名单和计分权重保留。
- **跨期行动**：带入上一等长周期、同一质量范围的待办/延期行动；没有结构化行动时按上一期“下一步行动”逐行带入。重复导入去重，状态变化保存在当前周期。
- **关联结果**：为行动填写已有 Markdown 笔记的完整路径，可打开实际交付。
- **洞见证据**：搜索本期笔记并预览前 12000 字，摘录最多 2000 字，保存时核对完整原文；也可只关联来源。摘录为保存时的快照，换行规范为 LF。文件重命名更新链接并保留原路径，文件删除后摘录仍保留。
- **报告携带上下文**：Markdown 报告包含来源统计、行动状态、继承周期、结果链接和证据摘录。新增行动、状态和反思沿用后台定期保存与“立即保存草稿”。

### 5. 原生 SVG 数据分析图表 (Analytics)
- **三大关键趋势**：内置原生轻量 SVG 绘制的每日贡献柱状图、写作变化折线图（新增/删除/改写）与时间投入折线图（交互活跃/专注时长）。
- **本月节奏**：对照上月同一天的累计，看本月是超前还是落后，以及照最近节奏月底能到哪里。
- **投入节律矩阵**：贡献、新增词数、交互活跃、Focus、新建笔记、完成任务六项指标按天对齐，颜色深浅取各指标在区间内的相对高低，一眼看出哪天是全面投入。
- **写作来源**：新增词数按保存方式拆成逐步写入、大段捕获、系统目录和未分类，每项附区间小趋势线。
- **投入去向**：按“笔记 × 天”统计投入落在哪些项目目录，环形图与明细列表联动高亮。
- **活跃时段**：交互活跃分钟按小时分布，找出一天里最活跃的连续 3 小时，并按星期 × 小时看规律。从 1.13.0 开始按小时记录，旧数据不倒推。
- **多周期与自适应**：支持 7 天、30 天与 90 天分析周期，自适应宽窄面板，支持键盘方向键与无障碍浏览。

### 6. 年度画像 (Yearly Portraits)
- **范围跟着数据走**：默认从第一条记录到今天（至少 30 天），也可切换完整日历年。
- **年轮**：每天一片花瓣绕成一圈，长度是贡献、颜色是当天最突出的投入方向。
- **知识指纹**：每天一根分段色条组成的条形码，配色跟随主题，可导出 PNG 分享。
- **月相日历**：每天一个月亮，满月是高峰日、新月是休息日，适合月度回看。
- **知识地层**：每周一层、按项目目录分色，看出哪些项目在持续积累。

### 7. 速记（flomo 式）
- **回车即记**：右侧「速记」视图或命令「记一条速记」，两秒记下想法，不打断手头的事。
- **一眼看到积累**：速记 / 标签 / 天数三个大数字、近 12 周热力图、连续天数与本月条数；速记以卡片展示，点 `#标签` 筛选。顶部导航与搜索框沿用 Obsidian 原生样式，和左侧文件列表对齐。
- **相关笔记与随机漫步**：纯本地计算内容相似度（中文双字、英文词、标签），展开每条速记的相关速记并说明共同的词；「漫步」页沿着相近速记一条条重新发现旧想法。不联网、不接 AI。
- **存到哪里由你决定**：通用模式追加到当天日笔记的 `## 速记` 段落；在 ANKS 库里可选每天一个 raw 采集件，交给 ANKS 的路由与编译流程。每条都是普通的 `> [!memo] HH:MM` Callout，离开插件也能读。
- **转化**：转为笔记；ANKS 模式下还能转为 question 或加入 Now 行动，原速记自动留下指向新文档的链接。
- **保存与重试**：保存失败保留输入；转问题继承来源 Topic。转化时添加隐藏的速记标识，回链失败后重试复用已生成的笔记或行动，不会重复创建。
- **正文展示**：卡片渲染 Markdown 加粗、列表与内部链接，标签仍可点击筛选；高级筛选收起后，生效条件仍显示在列表上方。
- **回顾**：每日回顾（同一天结果不变，可换一批，可设提醒时间）、去年今日、上月今日。
- **搜索与标签**：全文搜索与高级筛选（日期、包含 / 排除标签、无标签、是否已转化）；多级标签树，标签改名先预览、只改速记块。
- **URL 入口**：`obsidian://crisp-pulse-memo?vault=库名&text=内容&tags=灵感`，从快捷指令、Raycast、Alfred、PopClip 一步记录。
- **不依赖 ANKS**：以上功能在普通 Obsidian 库里完整可用；ANKS 只是可选的存储方式与转化目标。

### 8. Crisp Focus 专注计时深度联动
- **零侵入自动发现**：自动感知正在运行的 Crisp Focus 插件，无须复杂配置。
- **番茄钟专注累计**：完成专注会话后，专注时长自动纳入当日指标并折算贡献得分。
- **微动效联动**：当 Focus 处于专注计时状态时，Pulse 状态栏指示器呈现微呼吸脉冲动效。

### 9. 数据安全与隐私保障 (Local-First)
- **100% 本地运行**：所有统计计算均在本地完成，您的笔记内容、文件名和工作痕迹绝不离开您的设备。
- **防丢自愈备份**：在执行重置等破坏性操作前，系统自动在本地 `backups/` 目录生成时间戳快照。
- **安全防注入导出**：全量 CSV 导出经过公式注入清洗（Formula Injection Sanitization），安全无虞。

## 🚀 安装方式 (Installation)

### 方式一：通过 BRAT 安装（推荐）
1. 在 Obsidian 中安装并启用 **BRAT** 插件；
2. 打开 BRAT 设置，点击 **Add Beta plugin**；
3. 输入仓库地址：`letschips/crisp-pulse`；
4. 点击添加后，在“第三方插件”列表中启用 **Crisp Pulse** 即可。

### 方式二：手动安装
1. 从 [Releases](https://github.com/letschips/crisp-pulse/releases) 页面下载最新的发布包（包含 `main.js`, `manifest.json`, `styles.css`）；
2. 打开您的 Obsidian 库目录，进入 `.obsidian/plugins/`；
3. 新建文件夹 `crisp-pulse` 并将下载的文件放入其中；
4. 在 Obsidian 设置的“第三方插件”列表中重新载入并启用。

## 🔑 激活机制 (License & Activation)

- Crisp Pulse 是 **Crisp 插件套件** 的核心成员之一。
- 本插件基于 Ed25519 非对称公钥密码学实现本地验证与轻量在线设备防刷校验。
- **一次激活，全套受惠**：若您已在同一设备的其它 Crisp 插件（如 Crisp Focus、Crisp File Explorer）中完成正版激活，Crisp Pulse 将自动识别并继承授权状态，无需重复输入。库里有多张授权码时，会选用第一张对 Pulse 有效的。
- **未激活时可用的部分**：看板视图（热力图、六维指标、日明细）、数据记录、数据备份、CSV 与 JSON 导出。数据始终照常记录，激活后可以看到全部历史。
- **需要激活的部分**：知识复盘、数据分析、年度画像，以及复制周报、归档周报两个命令。

## 🛠️ 开发者与回归测试

本项目内置完整的本地自动化测试套件：

```sh
npm test
```

覆盖单元与回归场景，实际用例数量以 `npm run check` 输出为准（包括 Ed25519 签名验证、设备激活管理、有效行差异算法、任务状态机、多时间跨度过滤、周复盘生成、ANKS 归档与并发读写安全）。

速记文件流程检查：`npm run test:e2e:memo`，仅在操作系统临时目录创建测试文件。结果写入临时目录的 `crisp-pulse-memo-workflow-results.json`，可通过 `PULSE_MEMO_REPORT` 指定路径。

速记界面检查：在已加载当前插件的 Obsidian 中执行 `scripts/memo-runtime.e2e.js`（通过 `obsidian vault="库名" eval code="$(cat scripts/memo-runtime.e2e.js)"`）。它使用隔离 DOM 和延迟的内存保存，验证重复提交、草稿、Markdown、选区与筛选反馈，不写用户笔记；JSON 中 `passed: true` 表示全部通过。
